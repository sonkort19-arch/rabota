# Этап 8/10 — структурирование CSS без изменения оформления

## Что сделано
Два крупных файла стилей разбиты по зонам ответственности на шесть.
Последовательность CSS и каждое правило сохранены без изменений:

| Раньше | Теперь | Назначение |
|---|---|---|
| ui-alignment.css (1883 строки) | ui-alignment.css (742) | геометрия/базовые выравнивания |
| — | ui-alignment-orders.css (298) | список заказов и полосы вкладок |
| — | ui-alignment-home-calendar.css (317) | домашний экран и календарь |
| — | ui-alignment-mobile.css (526) | мобильная навигация, iPhone и WhatsApp |
| master-dense.css (1088 строк) | master-dense.css (491) | базовая плотная раскладка Рауля |
| — | master-dense-enhancements.css (597) | последующие точечные доработки |

Суммарное содержание этих двух исходных файлов не уменьшилось.
Это **разделение ответственности**, а не «ускорение на X%».
Стили загружаются в прежнем каскадном порядке; прочие файлы остаются
на тех же местах. `index.html` увеличился на четыре ссылки.

## Доказательство сохранности CSS
Новый тест `tests/css-stage8-regression.test.cjs` соединяет CSS-файлы
в исходном порядке и рассчитывает точный SHA-1 Git blob содержимого.
SHA двух оригинальных файлов:
- ui-alignment.css: 1669695e03aaf519514fa89a054a39c897fa6eef
- master-dense.css: d357ae642508e54d4749a8e4356f1a9061e66d2a

Оба SHA точно совпадают с содержимым исходных файлов
до разделения на этапе 7. Проверяются границы комментариев, блоков
и строк, наличие всех 21 CSS-ссылки, порядок перед master-dashboard,
master-dense и money-workspace, наличие предыдущих JS-модулей.

Актуализированы тесты:
- `tests/master-owner-cards.cjs`: читает обе части master-dense;
- `tests/ui-icon-layout.test.js`: проверяет все четыре части выравнивания;
- `tests/master-dense-layout.cjs`: использует реальный порядок CSS,
  включая завершающий money-workspace.css.

## Аудит повторений
В исходном ui-alignment.css найдено 2 повторяющихся блока с идентичными
селектором и декларациями, в master-dense.css — 1. Также несколько
селекторов переопределяются много раз. Их **не удаляли**: одинаковое
правило, повторённое ниже другого переопределения, может быть важным
из-за каскада CSS. Без просмотра поведения на iPhone безопасное
удаление не доказано.

## Потенциальный компромисс
Подключений CSS было 17, теперь 21: добавлено четыре отдельных сетевых
запроса. Упрощается поддержка файлов, но это не гарантирует ускорения
первой загрузки. На этапе 9/10 можно рассмотреть автоматическую сборку
одного CSS-файла с контролем исходного порядка, прежде чем внедрять её.

## Проверки и выпуск
- GitHub Actions `.github/workflows/stage08-css-regression.yml`:
  побайтовая эквивалентность, тесты ранее выделенных модулей и UI;
  также проверка компактной раскладки в WebKit.
- Перед основной версией требуется пройти весь CI и проверить реальные
  страницы на iPhone, роли, карточки заказов и платежные диалоги.
- Все изменения только в рабочей ветке этапа 8 (зависит от этапа 7).
  Main, Supabase и данные клиентов не изменены.

## Откат
Вернуть `index.html`, `ui-alignment.css`, `master-dense.css`
из ветки этапа 7 и удалить четыре новых CSS-файла.
