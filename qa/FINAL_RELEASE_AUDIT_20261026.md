## Возможность бесплатного резервного копирования
Организация Supabase имеет план `Free`, который **не включает ежедневные автоматические бэкапы**. Официально рекомендуется экспорт через Supabase CLI (`supabase db dump`). Ссылка:
https://supabase.com/docs/guides/platform/backups

Чтобы сохранить schema, data и roles, официальное руководство:
https://supabase.com/docs/guides/platform/migrating-within-supabase/backup-restore

```sh
# Выполнять ЛОКАЛЬНО, после установки Docker Desktop и Supabase CLI.
# CONNECTION_STRING получать в Supabase Dashboard -> Connect,
# пароль НЕ размещать в GitHub и чатах.
supabase db dump --db-url "[CONNECTION_STRING]" -f roles.sql --role-only
supabase db dump --db-url "[CONNECTION_STRING]" -f schema.sql
supabase db dump --db-url "[CONNECTION_STRING]" -f data.sql --use-copy --data-only
```

Обязательно убедиться, что архивы созданы и содержат все `public.rabota_*` таблицы. Важно: стандартный `supabase db dump` исключает платформенные `auth`, `storage` и системные схемы; для восстановления пользователей и объектов Storage нужен отдельный план. **Бэкап ещё не выполнен и не проверен на восстановление** — отсутствует безопасный доступ к паролю/строке подключения и инструмент скачивания бэкапа Supabase.
