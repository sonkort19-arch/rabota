# Этап 4/10 — выделение календаря и проверки свободных окон

## Результат
- Добавлен `calendar-model.js` (~118 строк): работа с датами, понедельник–воскресенье,
  отрисовка двух недельных панелей, кнопки предыдущей/следующей недели, выбор дня,
  проверка формата быстрого слота и статуса доступности.
- В `index.html` сохранены адаптеры `localDate`, `parseDate`, `addDays`,
  `formatDate`, `renderCalendar`, чтобы другие модули работали как раньше.
- Отрисовка недели и обработчики кнопок теперь вызывают отдельный модуль.
- Перед созданием быстрого заказа проводится та же проверка `available/tight`,
  авторизация ролей и формат даты/времени. Окончательная проверка остаётся в Supabase.
- Существующие `order-availability.js`, `quick-slots.js`, `order-model.js`
  и финансовый код не изменялись.
