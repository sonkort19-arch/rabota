# Этап 9/10 — общий слой запросов и утилит

## Область изменений
- `app-services.js` (65 строк) содержит:
  - `authRequest` для /auth/v1/ с прежними заголовками, телом и ошибками;
  - `dbRequest` для /rest/v1/, с прежним `ensureSession()` перед каждым запросом;
  - `friendlyError`, `normalizePhone`, `phoneForDisplay`.
- `index.html` вместо этих реализаций вызывает `sharedServices`.
- `index.html`: 2149 → 2129 строк (–20).
- `setSession`, `clearSession`, `ensureSession`, `refreshPromise`,
  роль текущего пользователя и фактический жизненный цикл сессии остались
  в исходном приложении.
- В `app-services.js` зависимости `getSession`, `ensureSession`,
  `fetch` передаются явно. Публичный Supabase URL и publishable key остаются
  в конфигурации index.html. `service_role` ключей нет.

## Что НЕ меняли
- Политики RLS, Supabase RPC, текущие записи и таблицы;
- Код авторизации Supabase, срок действия токена и одиночное обновление сессии;
- Логику сохранения заказов и расчёта финансов;
- Интерфейс, CSS, календарь, карточки мастера и ИИ;
- Основную ветку main и действующий production.
